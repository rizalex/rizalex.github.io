# (FREE Service) Personal Security Check

There are several free **Personal Cybersecurity** tool services useful for individuals to check their threat posture and manage security/ privacy risks. Notable examples include:


### [Have I Been Pwned](https://haveibeenpwned.com)
* Check if your email or personal information has been exposed in data breaches for better awareness of compromised accounts.

### Authenticator Apps (Google Authenticator/ Authy)
* Enable two-factor authentication, adding an extra security layer.

### Password Generators (LastPass/ F-Secure/ Bitdefender)
* Help create strong passwords to improve account security.

### Password Managers (Bitwarden/ LastPass/ 1Password) 
* A free and secure password storage and management.

### [F-Secure Online Scanner](https://www.f-secure.com/en/online-scanner)
* Scans your PC for viruses, malware, and other harmful items. It also has tools like Link Checker, Identity Theft Checker, and Router Checker for various online safety aspects.

### [VirusTotal](https://www.virustotal.com/gui/sign-in)
* Scan suspicious files, URLs, and domains through multiple antivirus engines to detect malware and phishing threats.

### [URLhaus](https://urlhaus.abuse.ch/browse/)
* Focuses on tracking and blocking malware-distributing URLs.
